---

## 🚀 Comenzando

Sigue estos pasos para configurar el proyecto localmente.

### 📋 Prerrequisitos

Asegúrate de tener instalado lo siguiente:

- [Node.js](https://nodejs.org/) (v20 o superior)
- [pnpm](https://pnpm.io/) (Recomendado)

### ⚙️ Instalación

1. **Clonar el repositorio:**

   ```bash
   git clone https://github.com/tu-usuario/dataplane.git
   cd dataplane
   ```

2. **Instalar dependencias:**
   ```bash
   pnpm install
   ```

### 💻 Desarrollo

Ejecuta el servidor de desarrollo:

```bash
pnpm dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador para ver los resultados.

### 🏗️ Construcción

Para crear una versión de producción:

```bash
pnpm build
```

Los archivos listos para producción estarán en el directorio `.next`.

---

## 🛠️ Tecnologías

- **Framework:** [Next.js 15](https://nextjs.org/) (App Router)
- **Estilos:** [Tailwind CSS 4](https://tailwindcss.com/)
- **Componentes:** [ShadCN](https://ui.shadcn.com/)
- **Iconos:** [Lucide React](https://lucide.dev/)
- **Gestión de Estado:** [Zustand](https://github.com/pmndrs/zustand)
- **Formularios:** [React Hook Form](https://react-hook-form.com/) + [Zod](https://zod.dev/)
- **Base de Datos:** [PostgreSQL](https://www.postgresql.org/) (vía `pg`)
